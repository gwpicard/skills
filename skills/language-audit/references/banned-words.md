# Banned Words

Full list with suggested replacements. Flag any of these in reviewed text.

| Word / phrase         | Replace with                                      |
|-----------------------|---------------------------------------------------|
| delve                 | look into, examine, explore                       |
| intricate             | complex, detailed — or describe the complexity specifically |
| tapestry              | describe the actual thing                         |
| pivotal               | key, critical — or say what specifically depends on it |
| underscore            | show, confirm, highlight                          |
| landscape (metaphor)  | field, area, space — or name the specific context |
| foster                | build, develop, encourage                         |
| testament             | evidence, proof, sign                             |
| enhance               | improve, strengthen, increase — be specific       |
| crucial               | important, necessary — or say what breaks without it |
| robust                | strong, reliable, thorough — be specific          |
| seamless              | smooth, straightforward — or describe the actual experience |
| vibrant               | active, busy, lively — be specific                |
| nestled               | located, sitting, set — be direct                 |
| thriving              | growing, active, busy — be specific               |
| leverage (verb)       | use                                               |
| commence              | start, begin                                      |
| navigate (metaphor)   | handle, manage, work through                      |
| unlock                | get, access, enable — be specific                 |
| game-changer          | describe the actual change                        |
| comprehensive         | complete, full, thorough — or list what it covers |
| paradigm shift        | describe the actual change                        |
| watershed moment      | turning point — or describe what changed          |
| transformative        | describe how it changes things specifically       |
| groundbreaking        | describe what's new about it specifically         |
| empower               | let, help, allow — be direct about what they can now do |
| synergy               | describe the specific combination or result       |
| holistic              | complete, full — or describe what it includes     |
| streamline            | simplify, speed up, reduce — be specific          |
| cutting-edge          | new, recent, current — or name the specific advancement |
| best-in-class         | describe what makes it better and compared to what |
| innovative            | describe the specific innovation                  |
| impactful             | describe the specific impact                      |
| actionable            | practical, specific, usable — be direct           |
| scalable              | say how it scales specifically                    |
| disruptive            | describe what it disrupts and how                 |
| ecosystem             | system, network, set of tools — be specific       |
| thought leader        | expert, researcher — or name the specific contribution |
| deep dive             | thorough look, detailed review, close examination |
| move the needle       | describe the specific measurable change           |
| circle back           | follow up, return to, revisit                     |
| bandwidth (metaphor)  | time, capacity, availability                      |
| unpack                | explain, examine, look at                         |
| learnings             | lessons, findings, results                        |
| ideate                | think through, brainstorm, develop ideas          |
| incentivise           | encourage, reward, motivate — be specific         |
| going forward         | from now on, after this — or just delete it       |
| at the end of the day | delete it                                         |
| it goes without saying| delete it and just say the thing                  |
