# <Brand> review rubric

Critics judge only these questions, so reviews from round to round can be compared. A finding outside the rubric is dropped, or proposed as a new question for the owner to accept. Each question names a pass example and a fail example from `exemplars/`.

| ID | Question | Pass | Fail |
|---|---|---|---|
| Q-01 | Does each screen have one thing that is clearly first? | exemplars/gold/<file> | exemplars/anti/<file> |
| Q-02 | Could this screen belong to a competitor with the logo swapped? (It should not.) | | |
| Q-03 | Is colour used only where it signals something? | | |
| Q-04 | Do the drawings follow the line and weight rules at real size? | | |
| Q-05 | Does a first-time visitor earn the target attributes: <attribute 1>, <attribute 2>, <attribute 3>? | | |
| Q-06 | Is every number, claim and name true and approved? | | |

For each question the critic answers pass or fail, names the element and its location, and gives one line of evidence.
